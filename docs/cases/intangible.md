## 景德镇陶瓷技艺传承

### 基本信息

| 项目 | 内容 |
|------|------|
| **所在地** | 江西省景德镇市 |
| **类型** | 传统技艺 |
| **列入非遗时间** | 2006年（国家级） |
| **列入世界遗产** | 2017年（陶瓷非遗 + 瓷文化景观） |
| **价值** | 中国陶瓷文化的杰出代表 |

### 背景介绍

景德镇是闻名世界的瓷都，有着两千多年的制瓷历史。从宋真宗景德元年（1004年）得名"景德"以来，景德镇陶瓷以"白如玉、明如镜、薄如纸、声如磬"的特质，成为中国陶瓷的代名词。2017年，"景德镇传统陶瓷烧制技艺"被列入首批国家级非物质文化遗产代表性项目名录。

### 技艺体系

景德镇传统陶瓷烧制技艺是一个完整的技艺体系，包括以下主要环节：

### 代表性技艺

#### 1. 青花瓷制作技艺

青花瓷是景德镇的代表性产品，其制作技艺包括：

- **青料配制**：调配氧化钴青料
- **釉下彩绘**：在坯体上绘制图案
- **罩釉烧制**：施透明釉后入窑烧制

#### 2. 颜色釉瓷烧制技艺

颜色釉瓷以釉色取胜，主要包括：

- **高温颜色釉**：郎窑红、祭红、美人醉等
- **中温颜色釉**：茶叶末、鳝鱼黄等
- **低温颜色釉**：粉彩、珐琅彩等

#### 3. 粉彩瓷制作技艺

粉彩瓷是釉上彩瓷的代表，以色彩柔和、层次丰富著称。

### 保护措施

!!! info "景德镇陶瓷技艺保护体系"
    景德镇建立了较为完整的非遗保护体系：

    1. **名录体系建设**：国家级、省级、市级非遗项目名录
    2. **传承人认定**：国家级、省级、市级非遗传承人
    3. **生产性保护**：在传承中保护，在保护中发展
    4. **数字化保护**：建立非遗数字档案

### 活化利用与创新发展

景德镇在保护传统技艺的同时，积极探索创新发展路径：

1. **文创开发**：开发陶瓷文创产品，拓展市场
2. **文化旅游**：发展陶瓷文化旅游，建设陶溪川等文创街区
3. **国际交流**：举办国际陶瓷艺术节，开展国际交流
4. **数字化转型**：利用电商平台拓展销售渠道

### 经验启示

!!! success "景德镇经验"
    景德镇陶瓷技艺保护的启示：

    - **活态传承**：传统技艺需要通过实践传承，在生产中保护
    - **人才培养**：重视传承人培养，建立多层次传承体系
    - **创新发展**：在传承基础上创新，保持技艺的生命力
    - **产业支撑**：依托产业发展，为传承提供物质基础
    - **文化认同**：增强公众对陶瓷文化的认同感

## 昆曲艺术保护

### 基本信息

| 项目 | 内容 |
|------|------|
| **类型** | 表演艺术 |
| **又称** | 昆剧、昆山腔 |
| **列入非遗时间** | 2001年（联合国教科文组织"人类口头和非物质遗产代表作"） |
| **地位** | "百戏之祖"、"中国最优雅的文学与戏剧"</p>

### 背景介绍

昆曲是中国最古老的剧种之一，起源于江苏昆山一带，距今已有六百多年历史。昆曲以其优美的唱腔、精致的表演、深邃的文学性，被誉为"百戏之祖"。2001年，昆曲被联合国教科文组织列为首批"人类口头和非物质遗产代表作"。

### 艺术特色

!!! info "昆曲艺术特点"
    昆曲具有以下独特的艺术特色：

    1. **水磨腔**：唱腔婉转细腻，如水磨般柔滑
    2. **载歌载舞**：表演身段与唱腔紧密结合
    3. **写意表演**：以虚拟的手法表现生活
    4. **文学性强**：剧本多出自文学家之手
    5. **曲牌体**：唱腔采用曲牌体结构

### 保护措施

#### 1. 剧目抢救

- 记录整理传统剧目
- 录制老艺术家演出资料
- 出版昆曲剧本、唱腔曲谱

#### 2. 人才培养

- 建立昆曲院团，培养专业演员
- 举办昆曲培训班
- 鼓励老艺术家收徒传艺

#### 3. 传播推广

- 举办昆曲艺术节
- 开展昆曲进校园活动
- 利用新媒体传播昆曲文化
