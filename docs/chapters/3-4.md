# 第三章 聚落类遗产保护与利用

## 3.4 聚落类遗产的更新利用

### 一、更新利用的指导思想

聚落类遗产的更新利用，应在保护优先的前提下，适度发挥其使用价值，实现保护与利用的协调。

**坚持保护第一**：更新利用不能损害文化遗产的历史价值。任何利用都应以不破坏文化遗产为前提。

**坚持以人为本**：更新利用应服务于聚落居民的生活需要，不能为迎合外来游客而牺牲居民利益。

**坚持因地制宜**：应根据聚落的具体情况，选择适宜的更新利用方式，不能照搬照抄其他地方的模式。

**坚持可持续发展**：更新利用应着眼于长期效益，不能为眼前利益而牺牲长远利益。

### 二、更新利用的主要模式

**文化旅游模式**：通过发展文化旅游，吸引游客参观游览，带动住宿、餐饮、购物等相关产业发展。这种模式适用于区位条件较好、具有一定知名度的聚落。

**特色农业模式**：发挥传统聚落的农业资源优势，发展有机农业、特色农产品加工、农事体验等业态。这种模式适用于以农业为主的传统村落。

**文创产业模式**：引入文化创意产业，利用传统建筑空间发展工作室、创意市集、艺术展览等。这种模式适用于具有一定艺术氛围、区位条件较好的聚落。

**社区居住模式**：保持聚落的居住功能，在改善基础设施的同时保留原有居民，让聚落继续作为活态的社区存在。这种模式适用于大多数传统聚落。

**综合保护模式**：综合运用多种方式，既发展文化旅游，又保护居民利益，既进行功能更新，又保持历史风貌。这种模式适用于价值较高、规模较大的聚落。

### 三、更新利用的规划设计

聚落更新利用的规划设计，应遵循以下原则：

**整体性原则**：规划设计应从聚落整体出发，统筹考虑各要素之间的关系，不能只关注单体建筑。

**历史性原则**：规划设计应尊重聚落的历史演变过程，保留不同历史时期的印记，而不是将聚落定格在某一特定时期。

**可逆性原则**：规划设计新增的内容应具有可逆性，即可以拆除而不损害原有的历史信息。

**协调性原则**：规划设计新增的内容应与原有风貌相协调，可以辨识，但不突兀。

### 四、更新利用的实施要点

**功能调整**：根据聚落的实际情况，合理调整功能布局。居住功能应作为聚落的基本功能予以保留；同时可以引入文化展示、旅游服务等功能。

**建筑修缮**：对历史建筑进行修缮时，应使用与原有材料相近的材料，采用与原有工艺相近的技术，保持建筑的原真性。

**环境整治**：对聚落的环境进行综合整治，清理杂物，改善卫生，绿化美化，恢复历史景观。

**设施提升**：在不破坏历史风貌的前提下，更新提升基础设施，提高防灾能力，改善居住条件。

**业态培育**：根据聚落特点，培育适合的业态，形成持续的吸引力，避免聚落空心化。
