# 第一章 文化遗产的定义与范畴

## 1.1 文化遗产的概念界定

### 一、文化遗产的定义

文化遗产是人类在社会历史实践中创造的、具有历史、艺术、科学价值的物质财富和精神财富的总和。这一概念的形成经历了漫长的历史演进过程，从最初的"古物"观念逐步发展为今天涵盖物质与非物质两大领域的综合性概念体系。

文化遗产的概念界定需要从多个维度进行理解。从时间维度看，文化遗产强调的是历史的积淀与传承，通常指具有较长历史年限、能够反映特定历史时期社会面貌的遗存。从价值维度看，文化遗产具有不可替代的历史见证功能、艺术审美功能、科学研究功能和社会教育功能。从保护维度看，文化遗产是不可再生的珍贵资源，一旦损毁将永远消失，因此需要采取特殊措施加以保护。

### 二、文化遗产的分类体系

根据联合国教科文组织的相关公约和国际通行做法，文化遗产通常分为以下几大门类：

**物质文化遗产**是具有物质形态的文化遗产，包括历史建筑、历史遗址、历史园林等不可移动文物，以及艺术品、历史文献、工艺品等可移动文物。物质文化遗产是人类社会活动的物质见证，承载着丰富的历史信息和文化内涵。

**非物质文化遗产**是指各族人民世代相传并视为其文化遗产组成部分的各种传统文化表现形式，以及与之相关的实物和场所。包括口头传统和表现形式、表演艺术、社会实践仪式和节庆活动、有关自然界和宇宙的知识和实践、传统手工艺等多种类型。

### 三、文化遗产的基本特征

文化遗产具有以下基本特征：

**稀缺性**：文化遗产是特定历史条件下的产物，不可复制，不可再生。随着时间的流逝和自然因素的侵蚀，文化遗产的数量只会减少而不会增加。

**唯一性**：每一处文化遗产都打上了独特的地域、民族和时代烙印，具有不可替代的独特价值。

**不可移动性**：大多数文化遗产与其所在的环境密不可分，一旦脱离原有环境将失去重要价值。

**脆弱性**：文化遗产通常年代久远，材质老化，抗灾能力弱，需要精心呵护。
