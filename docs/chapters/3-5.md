# 第三章 聚落类遗产保护与利用

## 3.5 聚落类遗产的制度保障

### 一、国际保护制度

国际社会对聚落类遗产保护的重视程度日益提高，建立了一系列保护制度框架。

**UNESCO世界遗产制度**：《保护世界文化和自然遗产公约》为聚落类遗产保护提供了国际准则。符合突出普遍价值标准的聚落可列入《世界遗产名录》，获得国际保护。意大利威尼斯历史城区、捷克克鲁姆洛夫历史城区、中国皖南古村落西递宏村等都是世界遗产中聚落类遗产的典型代表。

**历史城镇保护宪章**：国际文物保护与修复研究中心（ICCROM）及相关国际组织发布了一系列关于历史城镇保护的准则和建议，为聚落类遗产保护提供了技术指导。

### 二、中国保护制度

中国建立了较为完善的聚落类遗产保护制度体系。

**历史文化名城名镇名村保护制度**：2005年以来，国务院先后公布了多批国家历史文化名城、国家历史文化名镇名村。住房城乡建设部与国家文物局共同组织编制了保护规划，明确了保护范围、保护要素和保护要求。目前已公布国家历史文化名城135座、历史文化名镇312个、历史文化名村487个。

**传统村落保护制度**：2012年，住房城乡建设部等部门启动传统村落调查，建立了中国传统村落名录。目前已有6819个村落列入中国传统村落名录。传统村落保护强调保护优先、活态传承，尊重村民的主体地位，注重保护村落的历史格局、自然景观和传统文化。

**文物保护制度**：具有突出历史、艺术、科学价值的聚落建筑可认定为各级文物保护单位，受到《文物保护法》的保护。

### 三、保护规划编制

聚落类遗产保护规划是保护工作的重要依据。

**规划内容**：保护规划应包括资源调查评估、保护目标与原则、保护范围划定、保护要素识别、保护措施制定、利用与管理要求等内容。

**规划编制程序**：规划编制应经过现状调查、价值评估、方案比选、专家论证、公众参与等程序，确保规划的科学性和可操作性。

**规划实施监督**：规划批准后应严格执行，建立规划实施监督检查机制，及时纠正违规行为，确保聚落类遗产得到有效保护。

### 四、社会参与机制

聚落类遗产保护需要社会各界的广泛参与。

**公众参与**：鼓励居民参与聚落保护决策，了解居民诉求，保障居民权益。通过宣传教育提高公众保护意识，形成全社会关心支持聚落保护的良好氛围。

**社会力量参与**：鼓励企业、社会组织、个人等社会力量参与聚落保护，探索多元化的保护投入机制。

**国际合作**：开展聚落类遗产保护的国际交流与合作，学习借鉴国际先进经验，提升保护水平。
