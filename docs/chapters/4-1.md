# 第四章 建筑遗产保护与利用

## 4.1 文物建筑遗产的概念与类型

### 一、 建筑遗产的概念界定

 建筑遗产是指具有历史、艺术、科学价值的历史建筑，包括古代建筑、近代建筑和当代重要建筑。这些建筑承载着丰富的历史信息，是文化遗产的重要组成部分。

 文物建筑的基本特征**：

文物建筑具有历史见证价值。作为历史的物质载体，文物建筑记录了各个历史时期的社会状况、政治制度、经济水平、文化面貌等情况，是了解历史的重要资料。

文物建筑具有艺术审美价值。许多文物建筑在造型艺术、装饰艺术、园林艺术等方面具有很高的艺术成就，体现了当时的审美观念和工艺水平。

文物建筑具有科学技术价值。文物建筑的营造技术、结构体系、材料工艺等反映了当时的科技水平，对研究建筑史、技术史具有重要意义。

### 二、 建筑遗产的类型划分

**按建筑功能分类**：

居住建筑包括传统民居、官宦宅邸、商人宅第等，反映了不同阶层人们的居住方式和居住文化。典型代表有北京四合院、徽派民居、福建土楼、开平碉楼等。

宗教建筑包括佛教寺院、道教宫观、伊斯兰教清真寺、天主教堂、基督教堂等，是宗教文化的物质载体。如五台山寺庙群、武当山古建筑群、泉州清净寺、广州圣心大教堂等。

祭祀建筑包括坛庙、祠堂、先农坛、祈年殿等，是古代礼制文化的体现。如北京天坛、曲阜孔庙、山西晋祠等。

教育建筑包括书院、学堂、私塾等，是古代教育文化的物质载体。如岳麓书院、白鹿洞书院等。

商业建筑包括商铺、钱庄、会馆、客栈等，是商业文化的物质载体。如平遥古城日升昌票号、苏州山塘街商铺等。

防御建筑包括城墙、城门、关隘、烽火台、敌楼等，是军事防御设施。如长城、南京城墙、平遥古城墙等。

园林建筑包括皇家园林、私家园林、寺庙园林等，是园林艺术的精品。如颐和园、拙政园、留园、承德避暑山庄等。

交通建筑包括桥梁、渡口、驿站等，是交通发展的见证。如赵州桥、卢沟桥、泉州洛阳桥等。

工业建筑包括作坊、厂房、矿场等，是工业发展的遗存。如汉阳铁厂旧址、开滦煤矿矿场等。

**按历史时期分类**：

古代建筑主要指明清以前的建筑，包括唐、宋、元、明、清各代的建筑作品。这一时期的建筑在中国建筑史上占有重要地位，形成了成熟的建筑体系和独特的建筑风格。

近代建筑主要指1840年至1949年间的建筑。这一时期中国建筑受到西方建筑的影响，出现了中西合璧、新老并存的局面，产生了大量具有近代风格的建筑作品。

### 三、 建筑遗产的价值评估

文物建筑价值评估是确定保护级别、制定保护措施的重要依据。

**历史价值评估**：评估建筑的历史年代、历史事件关联、历史人物关联、历史文献价值等。

**艺术价值评估**：评估建筑的造型艺术、装饰艺术、工艺美术、园林艺术等方面的成就。

**科学价值评估**：评估建筑的结构技术、材料工艺、营造方法、规划设计等方面的科学成就。

**社会价值评估**：评估建筑在社区生活中的作用、文化认同功能、教育功能等。

### 四、 建筑遗产的分级保护

中国对文物建筑实行分级保护制度。

**全国重点文物保护单位**：由国务院核定公布，是最高级别的文物保护单位。目前已公布第八批全国重点文物保护单位共5058处。

**省级文物保护单位**：由各省、自治区、直辖市人民政府核定公布，数量众多，保护范围覆盖全省。

**市县级文物保护单位**：由市、县级人民政府核定公布，是文物保护的基础层级。

**文物保护点**：尚未公布为文物保护单位但具有较高价值的建筑，列入文物保护点名录，给予适当保护。
