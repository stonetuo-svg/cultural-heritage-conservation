# 第五章 产业文化遗产

## 5.3 工业遗产（制造业与矿业）

### 5.3.1 定义与内涵

工业遗产是产业遗产的核心组成部分，指工业活动中形成的具有保护价值的物质遗存与非物质遗存。

**经典定义**：《下塔吉尔宪章》定义工业遗产为"凡为工业活动所造建筑与结构、其中所含工艺与工具以及所处城镇与景观、及其所有物质和非物质表现"。这一定义涵盖了工业遗产的物质载体、生产设备、空间环境和文化表现等各个层面。

**中国语境下的工业遗产**：工信部国家工业遗产认定标准将工业遗产界定为"在中国工业长期发展中形成的、具有较高历史价值、科技价值、社会价值或艺术价值的工业遗存"。这一定义强调工业遗产价值的多维性。

**中国近代工业遗产的特殊背景**：中国近代工业遗产形成于特殊的半殖民地半封建社会背景下，经历了洋务运动引进西方技术、民族资本主义发展、三线建设时期工业布局调整等重要历史阶段，形成了独特的工业遗产类型和价值特征。

### 5.3.2 矿业遗产

**定义与范围**：矿业遗产是因矿产资源开采及初步加工活动形成的矿场、矿井、冶炼遗址及相关设施。包括地上和地下的采矿遗迹、选矿设施、冶炼工厂、运输系统、矿工居住区等。

**主要类型**：煤矿遗产是最重要的矿业遗产类型，包括矿井遗址、洗煤厂、矿工居住区、运输系统等。辽宁抚顺煤矿、山西大同煤矿等都是重要的煤矿工业遗产地。金属矿遗产包括铜矿、铁矿、金银矿的采选冶炼遗址，湖北大冶铜绿山古铜矿遗址是其中的典型代表。非金属矿遗产包括四川自贡井盐遗址、石料场、陶土矿等。

**工矿次生景观**：采矿活动形成的次生景观也是矿业遗产的重要组成部分，包括采掘沉陷区、废弃露天采矿场、尾矿堆场等。这些景观记录了采矿活动的环境影响，具有警示和教育的价值。

**价值特点**：矿业遗产的科技价值尤为突出，体现在采矿技术、巷道工程、冶炼工艺等方面。同时，矿业遗产具有重要的社会价值，承载着矿工群体的集体记忆和工业城镇的发展历程。

### 5.3.3 制造业遗产

**行业分类**：制造业遗产类型丰富。食品加工遗产包括酿酒作坊遗址（茅台、五粮液、汾酒老窖池）、榨油坊、制茶厂等。纺织遗产包括棉纺织厂、丝绸厂，无锡、南通等地的近代纺织工业遗产群具有重要价值。钢铁冶金遗产包括炼铁高炉、轧钢车间，首钢工业区、武汉钢铁厂是其中的代表。

**其他制造行业**：化工遗产包括化工厂遗址、制碱厂、制药厂等，华北制药厂是重要的医药工业遗产。机械制造遗产包括造船厂、机车厂、兵工厂，江南造船厂、二七机车厂等具有重要保护价值。建材遗产包括水泥厂、砖瓦窑、陶瓷厂等，近代景德镇工业遗产具有独特价值。能源遗产包括火力发电厂、水电站等。

**科技价值认定方法**：制造业遗产的科技价值认定需要依据机器设备与生产工艺进行分类分析。设备的技术先进性、生产工艺的代表性、设施的完整性等都是重要的评价指标。

### 5.3.4 价值认定

**历史价值**：工业遗产见证了近现代工业化的历史进程。从洋务运动引进机器生产，到民族工业的艰难发展，再到新中国的工业化建设，工业遗产记录了中国工业化的完整历程。

**科技价值**：工业遗产体现了特定历史时期工程技术水平与生产工艺特点，是研究工业技术史的重要资料。机器设备的更新换代、生产工艺的改进革新，都凝聚在工业遗产之中。

**社会价值**：工业遗产承载着工人阶级的集体记忆、劳作文化与工业社区生活。产业工人社区、工人文化宫、职工宿舍等都是工业社会的重要记忆载体。

**建筑与艺术价值**：工业建筑具有独特的美学特征。大跨度钢结构、几何形态、功能主义风格等，构成了工业建筑的美学体系。许多工业建筑被视为现代建筑史上的经典作品。

**经济价值**：旧工业建筑具有重要的再利用潜力。通过合理的功能转换，工业遗产可以焕发新的生命力，产生良好的经济效益。

### 5.3.5 保护与管理办法

**国际保护经验**：英国是工业考古学的发源地，在工业遗产保护领域具有开创性贡献。铁桥峡谷于1986年被列入世界遗产名录，成为世界上第一个工业遗产世界遗产。德国鲁尔区是工业区转型的典范，通过系统性的保护与再利用，将衰落的工业区改造为文化遗产旅游区。

**国内保护制度**：工信部建立了国家工业遗产认定制度，至今已认定七批共264项国家工业遗产。各省市也建立了省级工业遗产认定制度，认定近500项省级工业遗产。工业遗产保护与城市规划管理体系的衔接日益完善。

**再利用模式**：文化创意产业园是工业遗产再利用的常见模式，北京798艺术区、上海M50创意园、广州TIT创意园等都是成功案例。工业遗产博物馆模式通过建立专题博物馆展示工业遗产，中国工业博物馆、各地工业遗产博物馆发挥了重要的教育功能。城市公共空间模式将工业遗产改造为公园、景观，如纽约高线公园式的改造思路为国内提供了借鉴。
