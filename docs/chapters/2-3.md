# 第二章 文化遗产保护实践历程

## 2.3 文化遗产保护的基本原则

### 一、真实性原则

真实性原则是文化遗产保护的核心原则。它要求保护工作应保持文化遗产的历史真实性，避免任何有损于真实性的改动或添加。

真实性原则体现在多个方面：材料真实，要求保护修复使用的材料应与原有材料一致或相近；工艺真实，要求保护修复采用的技术方法应与原有建造工艺一致或兼容；形态真实，要求保持文化遗产的历史形态，避免改变其原状。

真实性原则还要求保护与文化遗产相关的历史信息。文化遗产的周边环境、历史文献、口述资料等，都是文化遗产不可分割的组成部分，都应加以保护。

### 二、完整性原则

完整性原则要求从整体上保护文化遗产，包括文化遗产本体及其历史环境。任何文化遗产都不是孤立的，它与周边的自然环境、人工环境密切相关，构成了一个有机的整体。

完整性原则要求在保护工作中，不能只关注文化遗产本体，而忽视其历史环境的保护。历史环境的破坏，会削弱文化遗产的价值，使其失去原有的意义。

完整性原则还要求保护文化遗产与社区生活的联系。文化遗产的保护不应割断其与当地社区的联系，而应促进文化遗产与社区发展的良性互动。

### 三、最小干预原则

最小干预原则要求在保护工作中，对文化遗产本体的干预应控制在必要的最低限度内。只有在必要的情况下，才能对文化遗产进行干预，且干预的程度应尽可能小。

最小干预原则强调，预防性保护优先于抢救性保护。应当通过加强日常养护、改善保存环境、消除安全隐患等措施，尽可能延长文化遗产的寿命，减少干预的次数和程度。

当必须进行干预时，应当遵循可逆性原则，即干预措施应当可以在不造成不可逆损害的情况下予以撤销。同时，干预措施应当具有可识别性，即新增部分应与原有部分有所区别。

### 四、可持续性原则

可持续性原则要求将文化遗产保护纳入社会可持续发展的整体框架，平衡保护与发展的关系，实现文化遗产的永续传承。

可持续性原则要求在保护工作中，不仅要保护文化遗产本体，还要保障当地居民的生存发展权益。要通过合理利用文化遗产资源，促进地方经济发展，改善居民生活条件。

可持续性原则还要求保护工作应着眼于长远，不能只顾眼前利益而损害文化遗产的长远保护。要建立长效机制，确保保护工作的持续性和有效性。

### 五、公众参与原则

公众参与原则要求在文化遗产保护中，广泛吸收公众参与，保障公众的知情权、参与权和监督权。

公众是文化遗产的创造者和传承者，也是文化遗产保护的主体。只有让公众认识到文化遗产的价值和意义，才能形成全社会共同保护文化遗产的良好氛围。

公众参与原则要求在保护规划的编制、保护项目的实施、保护效果的评估等各环节，都要广泛听取公众意见，接受公众监督。同时，要创造条件让公众参与保护工作，成为文化遗产保护的参与者、实践者。
