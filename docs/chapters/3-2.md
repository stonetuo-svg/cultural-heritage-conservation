# 第三章 聚落类遗产保护与利用

## 3.2 聚落类遗产的保护原则

### 一、整体性保护原则

整体性保护原则要求将聚落作为一个有机整体进行保护，不能将其割裂成孤立的建筑或构筑物。

整体性保护包括以下内容：

**保护聚落的空间格局**：包括聚落选址、总体布局、空间结构、道路系统、水系组织等。空间格局是聚落类遗产的核心价值所在，一旦破坏将难以恢复。

**保护聚落的环境要素**：包括聚落周边的山体、水体、植被、农田等自然环境要素，以及与传统聚落密切相关的历史环境要素。

**保护聚落的建筑群体**：包括各类历史建筑的本体及其相互关系。不能只保护个别重要建筑，而忽视其他一般建筑。

**保护聚落的人文要素**：包括社会结构、生活方式、民俗风情等非物质要素。聚落的人文要素是其活态价值的体现。

### 二、原真性保护原则

原真性保护原则要求保护聚落的历史真实性，保持聚落的本来面貌。

**保持历史信息的完整**：聚落在长期历史发展过程中积淀的历史信息，是其价值的重要来源。保护工作应尽可能保存这些历史信息，不应随意添加或删减。

**保护历史建筑的原有材料和工艺**：对于历史建筑的修缮，应尽可能使用原有材料，采用传统工艺。替换构件应慎重，只有在原有构件确实无法保留的情况下才可替换。

**保护历史建筑的原有权属关系和功能**：传统聚落中的建筑，往往都有其特定的功能用途。保护工作应尊重这种历史形成的权属关系和功能格局。

**保护历史环境的原有状态**：聚落周边的自然环境和人工环境，是聚落形成发展的基础条件，应予以保护。

### 三、可持续性保护原则

可持续性保护原则要求在保护聚落的同时，保障聚落居民的生存发展权益，实现保护与发展的协调统一。

**改善居民生活条件**：传统聚落通常基础设施落后，居住条件较差。保护工作应在保持历史风貌的前提下，逐步改善聚落的基础设施和居住条件。

**发展聚落经济活力**：传统聚落如果失去经济活力，就会逐渐空心化、衰败化。保护工作应通过发展文化旅游、特色产业等方式，增强聚落的经济活力。

**传承聚落文化传统**：传统聚落的生命力在于文化的活态传承。保护工作应支持社区居民在聚落中继续生活，继续开展传统活动，保持聚落的活态特征。

**建立长效保护机制**：聚落保护是一项长期工作，需要建立长效机制。要明确保护责任，筹措保护资金，加强日常管理，确保保护工作的持续性。

### 四、分类保护原则

分类保护原则要求根据聚落类遗产的价值和状况，采取差异化的保护措施。

**对于具有突出价值的聚落**：应实行最严格的保护，限制任何可能改变其历史风貌的开发建设活动。

**对于具有一般价值的聚落**：可以在保护核心要素的前提下，允许进行适度的更新改造。

**对于价值较低但仍有一定保留意义的聚落**：可以进行有计划的整治改造，改善居住条件，消除安全隐患。

**对于已经没有保留价值的聚落**：可以通过征收、置换等方式，妥善处理后再进行新的建设。

分类保护应建立在科学的价值评估基础上。价值评估应综合考虑聚落的历史价值、艺术价值、科学价值、社会价值等因素。

### 五、公众参与原则

公众参与原则要求在聚落保护中广泛吸收居民参与，保障居民的知情权、参与权和监督权。

**保障居民的居住权**：聚落是居民世代居住的家园。保护工作不应以赶走居民为代价，而应在保护的前提下保障居民的居住权益。

**尊重居民的使用习惯**：传统聚落是居民长期生活形成的空间。保护工作应尊重居民的使用习惯和合理需求，不应脱离实际地追求某种"理想"状态。

**调动居民的积极性**：居民是聚落保护的主体。只有让居民认识到保护的价值和意义，才能形成保护合力。要通过教育培训、宣传引导等方式，提高居民的保护意识。

**分享保护的收益**：聚落保护的收益应让居民共享。如果发展旅游等产业获得的收益，主要应用于改善聚落基础设施和居民生活条件。
