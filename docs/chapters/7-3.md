# 第七章 非物质文化遗产

## 7.3 非物质文化遗产的保护措施

### 一、调查与认定

调查与认定是保护工作的基础。

**全面普查**：通过田野调查、文献梳理等方式，对本地区的非物质文化遗产进行全面普查，摸清家底，建立档案。

**分级认定**：根据价值大小和保护需要，将非物质文化遗产分为不同级别进行保护。国家、省、市、县四级名录体系是非遗认定的主要方式。

**代表性项目**：从名录项目中认定代表性项目，代表性项目是保护的重点对象。目前，全国共有国家级非遗代表性项目1557项。

**代表性传承人**：从传承群体中认定代表性传承人，代表性传承人是非遗活态传承的关键。目前，全国共有国家级非遗代表性传承人3068人。

### 二、记录与建档

记录与建档是保存非遗信息的有效手段。

**数字化记录**：运用录音、录像、摄影、三维扫描等现代技术手段，对非遗项目进行全面记录，建立数字档案。

**文字记录**：组织专业人员对非遗项目进行文字记录，编写项目简介、传承脉络、技艺流程、代表作品等档案材料。

**实物征集**：征集与非遗项目相关的工具、实物、作品等，建立专门的非遗实物档案库。

**数据库建设**：建设非遗数据库，将数字化记录、文字档案、实物信息等进行整合，实现信息共享。

### 三、保护与传承

保护与传承是非遗保护的核心工作。

**抢救性保护**：对濒危、将要失传的非遗项目进行紧急抢救，采取录音录像、培养传承人、整理档案等措施，防止其消亡。

**生产性保护**：对于具有生产性质的传统技艺、传统美术类非遗，可以采取生产性保护方式，在保护核心技艺的基础上适度开发利用。

**整体性保护**：对非遗项目集中的区域，可以采取整体性保护方式，建立文化生态保护区，维护非遗赖以生存的文化生态。

**传承人培养**：传承人是非遗活态传承的关键。要通过认定补贴、传习活动、技艺培训等方式，支持传承人开展传承活动。

### 四、展示与传播

展示与传播是扩大非遗影响、增进公众了解的重要途径。

**博物馆展示**：通过博物馆、常设展馆等，展示非遗项目的历史渊源、技艺流程、代表作品等，让公众直观了解非遗。

**活动展示**：通过举办非遗节庆、非遗展演、非遗进校园等活动，让公众近距离感受非遗的魅力。

**媒体传播**：通过电视、广播、网络、报刊等媒体，宣传报道非遗项目，扩大非遗的社会影响。

**数字化传播**：通过建立非遗网站、开发非遗APP、制作非创视频等方式，推进非遗的数字化传播。

### 五、研究与利用

研究与利用是深化保护、发挥价值的重要手段。

**学术研究**：组织开展非遗的理论研究、历史研究、技艺研究等，为保护工作提供学术支撑。

**人才培养**：依托高等院校、研究机构等，培养非遗研究人才和保护管理人才。

**合理利用**：在保护好的前提下，合理利用非遗资源，发展文化旅游、文化创意产业等，发挥非遗的经济价值。
