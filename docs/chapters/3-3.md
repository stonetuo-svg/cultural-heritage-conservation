# 第三章 聚落类遗产保护与利用

## 3.3 聚落类遗产的保护实践

### 一、历史文化名城名镇名村保护

中国建立了历史文化名城、历史文化名镇、历史文化名村保护制度，形成了国家、省、市、县四级保护体系。

**历史文化名城**：是指保存文物特别丰富、历史建筑集中成片、具有重要历史价值的城市。目前全国已公布137座国家历史文化名城。

**历史文化名镇**：是指保存文物特别丰富、历史建筑集中成片、具有重要历史价值的镇。目前全国已公布312个国家历史文化名镇。

**历史文化名村**：是指保存文物特别丰富、历史建筑集中成片、具有重要历史价值的村。目前全国已公布487个国家历史文化名村。

历史文化名城名镇名村的保护，规划先行。保护规划应明确保护对象、划定保护范围、制定保护措施、规范建设活动。

### 二、传统村落保护

传统村落是指形成年代较早，拥有较丰富的传统资源，具有一定历史、文化、科学、艺术、社会、经济价值，应予以保护的村落。

2012年，住房城乡建设部等部门联合启动了传统村落调查，建立了传统村落名录。目前，全国共有五批6819个中国传统村落。

传统村落保护的重点包括：保护村落的传统格局和历史风貌，保护村落的文物古迹和历史建筑，保护村落的非物质文化遗产，保护村落的传统生产生活方式。

国家财政设立了传统村落保护专项资金，支持村落的保护发展工作。同时，鼓励社会力量参与传统村落保护，形成了多元化的保护格局。

### 三、历史街区保护

历史街区是指保存历史遗迹较为完整、历史建筑集中成片、能够较完整地体现某一历史时期某一地区传统风貌和地方特色的街区。

历史街区保护的重点是保护街区的空间格局和建筑风貌。主要措施包括：

**划定保护范围**：明确核心保护范围和建设控制地带，制定差异化的管控要求。

**保护修缮历史建筑**：对街区内的历史建筑进行排查鉴定，对有损毁危险的建筑进行抢救性保护，对一般历史建筑进行日常养护。

**整治不协调建筑**：对与历史风貌不协调的新建筑，进行外观整治或拆除改造。

**改善基础设施**：在保持历史风貌的前提下，更新老化的市政管网，改善交通条件，提高防灾能力。

**发展文化功能**：通过引入文化展示、非遗传承、文创产业等功能，激发街区的活力。

### 四、聚落保护与发展的协调

聚落保护不能脱离发展，发展的目的也是为了更好地保护。要实现保护与发展的协调，应注意以下几点：

**科学制定保护规划**：保护规划应立足聚落实际，统筹保护与发展的关系，明确发展方向和重点，避免盲目开发。

**合理利用遗产资源**：要充分发挥聚落类遗产的资源优势，发展文化旅游、特色农业、文创产业等，实现遗产保护与经济发展的双赢。

**改善聚落人居环境**：要加大投入，改善聚落的基础设施和公共服务设施，提高居民生活质量，让居民愿意留在聚落、热爱聚落。

**建立利益共享机制**：聚落保护开发的收益应合理分配，让社区居民得到实惠，形成保护与发展的良性循环。
