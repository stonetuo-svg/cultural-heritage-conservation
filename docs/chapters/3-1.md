# 第三章 聚落类遗产保护与利用

## 3.1 聚落类遗产的认知基础

### 一、聚落的概念与特征

聚落是人类聚居和活动的场所，是人类适应自然、改造自然的结果。聚落类遗产是指具有历史价值、文化价值、科学价值和社会价值的传统聚落及其构成要素。

**聚落的基本特征**：

聚落具有地域性特征。不同地区的聚落受自然环境、气候条件、资源禀赋等因素的影响，形成了各具特色的聚落形态。北方聚落多为合院式布局，南方聚落则多见梳式布局或客家围屋等形式。聚落选址讲究风水理念，背山面水、负阴抱阳是常见的理想模式。

聚落具有整体性特征。聚落是一个有机的整体，建筑、街巷、广场、水系、植被等要素相互关联、相互制约，共同构成完整的聚落空间体系。单独保护某一要素而忽视其他要素，会破坏聚落的整体价值。

聚落具有历史层积特征。聚落在漫长的历史发展过程中不断演变，新的建设与旧的遗存相互叠加，形成丰富的历史层积。不同历史时期的建筑和空间并存，反映了聚落演变的轨迹。

### 二、聚落类遗产的类型

根据不同的分类标准，聚落类遗产可以分为多种类型。

**按形成时代分类**：

可分为古代聚落、近代聚落和现代聚落。古代聚落主要指明清以前形成的传统聚落，具有较为完整的历史风貌；近代聚落是近代以来形成的具有一定历史价值的聚落；现代聚落则是20世纪中后期建设的具有时代特色的聚落。

**按空间形态分类**：

可分为团块状聚落、带状聚落和分散型聚落。团块状聚落呈集中布局，如环状、十字形等；带状聚落沿河流、道路等线性要素延伸；分散型聚落则散布于较大范围内，如散村、寨子等。

**按功能分类**：

可分为农业聚落、手工业聚落、商业聚落、军事聚落、宗教聚落等。不同功能的聚落具有不同的空间特征和文化内涵。

### 三、聚落类遗产的价值

聚落类遗产具有多重价值，是人类社会宝贵的文化遗产。

**历史价值**：聚落是历史的载体，保存了大量历史信息。通过聚落可以了解不同历史时期的社会组织、生产生活方式、文化信仰等情况，是研究人类社会发展的重要资料。

**文化价值**：聚落是文化的容器，承载着丰富的民俗文化、宗族文化、宗教文化等。聚落中的建筑、空间、民俗等都是文化的重要表现形式，是文化认同和文化传承的重要依托。

**科学价值**：聚落在选址、布局、建造等方面积累了丰富的经验，体现了先民的智慧。传统聚落的营造技术、建筑工艺、生态理念等对当代建筑设计、城乡规划具有借鉴意义。

**社会价值**：聚落是社区生活的空间，具有重要的社会功能。传统聚落中的人际关系、社会组织、公共活动等维系着社区的凝聚力，是社会和谐的重要基础。

### 四、聚落类遗产的构成要素

聚落类遗产由多种要素构成，主要包括以下几类：

**物质要素**：包括自然环境要素（如地形、水系、植被、气候等）和人工环境要素（如建筑、街巷、广场、桥梁、堤坝、水井等）。物质要素是聚落的空间载体。

**非物质要素**：包括民俗文化、宗族组织、民间信仰、手工技艺、传统产业、节庆活动等。非物质要素是聚落的文化内涵，与物质要素相互依存、相互影响。

**聚落景观**：是物质要素与非物质要素共同作用形成的整体景观效果，包括聚落的轮廓线、天际线、视廊、景观节点等。聚落景观是聚落类遗产的整体呈现。
