# 第一章 文化遗产的定义与范畴

## 1.3 国际文化遗产保护体系

### 一、国际公约体系

20世纪60年代以来，国际社会逐步建立了较为完整的文化遗产保护公约体系。1964年通过的《威尼斯宪章》确立了文化遗产保护的基本原则，成为国际文化遗产保护的重要文献。

1972年，联合国教科文组织通过了《保护世界文化和自然遗产公约》，建立了世界遗产制度。该公约将文化遗产和自然遗产纳入统一保护框架，提出了"突出普遍价值"的概念，建立了国际合作保护的机制。截至目前，世界遗产总数已超过1100项，成为国际社会最具影响力的文化遗产保护行动。

2003年，联合国教科文组织通过了《保护非物质文化遗产公约》，将非物质文化遗产保护纳入国际公约体系。该公约强调非物质文化遗产对文化多样性和人类创造力的重要意义，倡导以社区为主体的保护理念。

2005年，《保护非物质文化遗产公约》又通过了《保护文化多样性公约》，进一步强调文化多样性对人类的重要意义。这些国际公约共同构成了当代国际文化遗产保护的法律基础。

### 二、国际组织机构

联合国教科文组织是国际文化遗产保护的主导机构，负责制定国际公约、指导各国保护工作、开展国际合作、组织世界遗产申报与管理等各项工作。

国际古迹遗址理事会（ICOMOS）是文化遗产保护领域的专业咨询机构，负责对申报世界遗产的项目进行评估，为各国提供技术指导，参与制定保护准则和标准。

国际文物保护与修复研究中心（ICCROM）专注于文物保护修复技术的研发和推广，组织专业人员培训，开展文物保护领域的科学研究。

### 三、国际合作机制

世界遗产基金为发展中国家保护世界遗产提供资金支持和技术援助。非遗基金用于支持非遗项目的保护传承工作。此外，各国之间还通过双边合作、区域性合作等方式开展文化遗产保护领域的交流与合作。
